# DivinityAGI — Spiritual AI For Everyone

Rebuilt landing page for [divinityagi.com](https://divinityagi.com).

## Quick Start
```bash
npm install
npm run dev
```

## Deploy
Push to GitHub, then import in [vercel.com/new](https://vercel.com/new). Framework: Vite.

## Images
`USE_REAL_IMAGES = true` in src/App.tsx loads all images from divinityagi.com.
